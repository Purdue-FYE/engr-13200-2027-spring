6.1.1. PCMs: Logic and Modularity#

Relational Operators#

Relational operators compare two values or expressions to determine whether a condition is true or false. These comparisons are commonly used in programming to make decisions based on data.

Table 6.1 Relational Operators#

Operator

Description

Example

==

Equal to

5 == 5

~=

Not equal to

5 ~= 3

>

Greater than

5 > 3

<

Less than

5 < 3

>=

Greater than or equal to

5 >= 3

<=

Less than or equal to

5 <= 3

In MATLAB, the result of a relational operation is a logical value where 1 represents true and 0 represents false.

MATLAB vs. Python

Most relational operators work the same way in MATLAB and Python. However, MATLAB uses ~= for “not equal to,” while Python uses !=.

Example: Comparing Scalar Values#

An engineering system has a maximum allowable temperature of 80°C. The following code determines whether a measured temperature exceeds this limit.

temperature = 85;
maxTemp = 80;

tempCheck = temperature > maxTemp

produces

tempCheck =

  logical

   1

Since the measured temperature is greater than the maximum allowable temperature, MATLAB returns 1 (true).

Example: Comparing Values in Arrays#

Relational operators can also compare corresponding elements in arrays, returning a logical array of the same size. The following example identifies which temperature measurements exceed the maximum allowable temperature of 80°C.

temperatures = [75, 82, 79, 91, 85];
maxTemp = 80;

tempCheck = temperatures > maxTemp

produces

tempCheck =

  1×5 logical array

   0   1   0   1   1

The second, fourth, and fifth temperatures exceed the maximum allowable temperature. Each of these positions contains a 1 in the resulting logical array.

Logical Operators#

Logical operators combine or modify conditions to evaluate whether an expression is true or false. While relational operators compare values, logical operators allow multiple conditions to be evaluated together.

MATLAB uses four primary logical operators: AND, OR, NOT, and XOR (exclusive OR).

Table 6.2 Logical Operators#

Operator

Description

MATLAB Syntax

AND (&)

True when both conditions are true

A & B

OR (|)

True when at least one condition is true

NOT (~)

Reverses the logical value

Unlike AND, OR, and NOT, XOR is a built-in MATLAB function rather than a symbolic operator.

MATLAB vs. Python

In Python, logical conditions are commonly combined using and, or, and not. MATLAB uses &, |, and ~ for element-wise logical operations.

Truth Tables#

A truth table shows the result of a logical operation for every possible combination of input values. The following table summarizes the behavior of the four logical operators.

Notice that OR returns true when either or both conditions are true, while XOR returns true only when exactly one condition is true.

Example: Combining Conditions with Scalars#

An engineering system operates within an acceptable temperature range of 20°C to 80°C. The following code determines whether a measured temperature falls within this range.

  • Mathematically, the condition can be expressed as \( 20 \leq T \leq 80 \).

  • In MATLAB, each comparison must be written separately and combined using the logical AND (&) operator.

temperature = 65;
minTemp = 20;
maxTemp = 80;

withinRange = temperature >= minTemp & temperature <= maxTemp

produces

withinRange =

  logical

   1

Since the temperature satisfies both conditions, withinRange is 1 (true). If the temperature were below 20°C or above 80°C, the result would be 0 (false).

Example: Combining Conditions with Arrays#

Logical operators can also evaluate multiple conditions for each element of an array. The following example identifies temperatures that fall outside the acceptable range.

temperatures = [15, 35, 82, 60, 91];
minTemp = 20;
maxTemp = 80;

outsideRange = temperatures < minTemp | temperatures > maxTemp

produces

outsideRange =

  1×5 logical array

   1   0   1   0   1

The first, third, and fifth temperatures are outside the acceptable range, so their corresponding positions contain 1 in the logical array. The & and | operators evaluate corresponding elements when used with arrays, allowing multiple conditions to be combined into a single logical array.

When an expression contains multiple types of operators, MATLAB follows a specific order of operations to determine which operations are evaluated first. Understanding this order is important when combining arithmetic calculations, relational comparisons, and logical conditions.

Example: Evaluating a Logical Expression#

Consider a system that monitors temperature and pressure. An alert should be triggered when the temperature exceeds 80°C or when the pressure exceeds 150 kPa while the cooling system is inactive. The conditions can be combined into a single logical expression.

temperature = 75;
pressure = 165;
coolingActive = false;

triggerAlert = temperature > 80 | pressure > 150 & ~coolingActive

MATLAB evaluates the expression according to operator precedence:

  1. ~coolingActive evaluates to 1 because the cooling system is inactive.

  2. temperature > 80 evaluates to 0.

  3. pressure > 150 evaluates to 1.

  4. 1 & 1 evaluates to 1.

  5. 0 | 1 evaluates to 1.

triggerAlert =

  logical

   1

The alert is triggered because the pressure exceeds the allowable limit while the cooling system is inactive.

Using Parentheses#

Although MATLAB automatically follows operator precedence, parentheses can make complex logical expressions easier to read and interpret.

The previous expression can be rewritten as:

triggerAlert = (temperature > 80) | ((pressure > 150) & ~coolingActive);

Both expressions produce the same result. However, the parentheses make it easier to identify which conditions are evaluated together.

Short-Circuit Logical Operators#

MATLAB also provides short-circuit logical operators, && and ||. Unlike & and |, which can evaluate arrays element by element, short-circuit operators can only be used with scalar logical conditions.

Short-circuit operators only evaluate the second condition when it is necessary to determine the result of the logical expression.

Table 6.4 Short-Circuit Operators#

Operator

Description

Behavior

&&

Short-circuit AND

Skips the second condition if the first is false

||

Short-circuit OR

Skips the second condition if the first is true

Example: Short-Circuit AND#

The following code checks whether a temperature measurement is within an acceptable range.

temperature = 65;
minTemp = 20;
maxTemp = 80;

withinRange = temperature >= minTemp && temperature <= maxTemp;

If temperature >= minTemp is false, MATLAB does not evaluate the second condition because both conditions must be true for the entire expression to be true.

Short-circuit operators are commonly used in selection structures when evaluating multiple scalar conditions. Use & and | for element-wise logical operations with arrays. Use && and || when short-circuit evaluation is needed for scalar conditions.

Selection Structures#

A selection structure allows a program to execute different commands based on whether a logical condition is true or false. Rather than executing every command sequentially, MATLAB uses selection structures to determine which commands should be executed. As you learned in ENGR 131, Python uses if, elif, and else statements to control which commands are executed. MATLAB uses similar selection structures, but with some important differences in syntax.

Types of Selection Structures#

MATLAB supports the same general types of selection structures introduced in Python. The following examples compare the syntax of each structure in both languages.

if-end Structure*#

An if-end structure executes commands only when its condition is true. If the condition is false, MATLAB skips those commands and continues after end.

Python

MATLAB

 
temperature = 85

if temperature > 80:
    print("Warning: High temperature")

temperature = 85;

if temperature > 80
    fprintf('Warning: High temperature\n');
end

if-else-end Structure#

An if-else-end structure provides two possible paths. Exactly one branch executes based on whether the condition is true or false.

Python

MATLAB

 
temperature = 65

if temperature > 80:
    print("Warning: High temperature")
else:
    print("Temperature is within range")

temperature = 65;

if temperature > 80
    fprintf('Warning: High temperature\n');
else
    fprintf('Temperature is within range\n');
end

if-elseif-else-end Structure#

An if-elseif-else-end structure allows a program to choose between multiple outcomes. Conditions are evaluated from top to bottom, and only the first branch with a true condition executes. An elseif statement must include a condition, while else does not. Multiple elseif statements can be included, but only one else statement can be used.

Python

MATLAB

 
temperature = 27

if temperature > 30:
    print("Warning: High temperature")
elif temperature >= 20:
    print("Temperature is within range")
else:
    print("Warning: Low temperature")

temperature = 27;

if temperature > 30
    fprintf('Warning: High temperature\n');
elseif temperature >= 20
    fprintf('Temperature is within range\n');
else
    fprintf('Warning: Low temperature\n');
end

Example: Classifying Flight Speed#

An engineering team is testing airfoils at different flight speeds. The Mach number represents the ratio of an object’s speed to the speed of sound. The team needs to classify each flight speed according to the following criteria:

Mach Number

Classification

Less than 0.8

Subsonic

0.8 to 1.3, inclusive

Transonic

Greater than 1.3

Supersonic

The following MATLAB code uses a selection structure to determine the classification.

machNumber = 1.1;

if machNumber < 0.8
    classification = "Subsonic";
elseif machNumber <= 1.3
    classification = "Transonic";
else
    classification = "Supersonic";
end

fprintf('Flight classification: %s\n', classification);

Running the code produces: Flight classification: Transonic

  • MATLAB first evaluates whether machNumber < 0.8. Since this condition is false, MATLAB moves to the elseif condition.

  • The second condition, machNumber <= 1.3, is true, so MATLAB assigns "Transonic" to classification and skips the else branch.

  • Notice that the second condition does not need to check whether the Mach number is greater than or equal to 0.8. Values below 0.8 have already been handled by the first branch.

Selection Structures and Flowcharts#

The flight classification example can also be represented using a flowchart.

        flowchart TD
    A([Start]) --> B[Set Mach number]
    B --> C{Mach number < 0.8?}
    C -->|True| D[Classification = Subsonic]
    C -->|False| E{Mach number <= 1.3?}
    E -->|True| F[Classification = Transonic]
    E -->|False| G[Classification = Supersonic]
    D --> H[/Display classification/]
    F --> H
    G --> H
    H --> I([End])

Each decision symbol corresponds to an if or elseif condition in the MATLAB code. The true and false branches show which commands execute based on the result of each comparison.

Testing Selection Structures#

When testing a selection structure, it is important to verify that each possible branch produces the expected result. Values at the boundaries between conditions should also be tested to confirm that the relational operators are correct.

For the flight classification example, consider the following test cases:

Test Case

Mach Number

Expected Classification

3

1.3

Transonic

5

1.8

Testing values of exactly 0.8 and 1.3 is especially important because these values define the boundaries between classifications.

Best Practice

Develop test cases that exercise every branch of a selection structure and verify that the actual outputs match the expected results.

User-Defined Functions#

As you learned in ENGR 131, a user-defined function (UDF) is a reusable block of code created to perform a specific task. Functions help organize programs into smaller components, reduce repeated code, and make programs easier to test and maintain.

MATLAB includes many built-in functions, such as mean(), sum(), and sqrt(). You can also create your own functions to perform calculations or operations specific to an engineering problem.

Scripts vs. Functions#

Both MATLAB scripts and functions are saved as .m files. However, scripts execute commands in the base workspace, while functions use their own workspaces and communicate through input and output arguments. Variables created inside a function are not automatically available outside that function.

Defining a User-Defined Function#

MATLAB functions begin with a function definition line that identifies the function name, input arguments, and output arguments.

The general syntax is:

function output = function_name(input1, input2)
    % Function commands

In MATLAB, the function definition line must follow these rules:

  • The first word is function.

  • Output arguments appear before the function name, followed by =.

  • Input arguments appear in parentheses after the function name.

  • Multiple input arguments are separated by commas.

  • Multiple output arguments are enclosed in square brackets ([]).

  • The function name must match the .m file name (without the .m extension).

MATLAB vs. Python#

In Python, functions are defined using def and return values using the return statement. MATLAB uses the function keyword and identifies its output variables in the function definition line.

Table 6.7 Function Definition Comparison#

Python

 
def rectangle_properties(length, width):
    area = length * width
    perimeter = 2 * (length + width)
    return area, perimeter

MATLAB

 
function [area, perimeter] = rectangle_properties(length, width)
    area = length * width;
    perimeter = 2 * (length + width);

Both functions calculate the area and perimeter of a rectangle. In Python, the return statement specifies which values are returned. In MATLAB, the output variables are identified in the function definition line and enclosed in square brackets ([]) when multiple outputs are returned.

MATLAB Function End Statements

Unlike MATLAB selection structures, which require an end statement, standalone functions saved in their own .m files do not require one. However, functions defined within scripts require end to close the function definition. In ENGR 132, you will create separate function files using the provided function template, so an end statement is optional.

Creating and Calling a Function#

In ENGR 132, you will use the provided MATLAB function template to create UDFs. The template includes a function definition line, documentation header, and sections for initialization, calculations, and formatted displays.

The documentation header identifies the function’s purpose, input and output arguments, and assignment information. Each argument should include a description and its units, when applicable.

Example: Gamma Radiation Shielding#

A nuclear engineering team is designing metal shields to reduce exposure to gamma radiation. The exposure rate behind a shield can be calculated using:

\[ D = D_0 e^{-\mu x} \]

Where:

  • \(D\) is the shielded exposure rate (mR/hr).

  • \(D_0\) is the unshielded exposure rate (mR/hr).

  • \(\mu\) is the linear attenuation coefficient (cm\(^{-1}\)).

  • \(x\) is the shield thickness (cm).

The function gamma_exposure uses three input arguments to calculate one output argument.

File name: gamma_exposure.m

function shieldedExposure = gamma_exposure(thickness, attenuationCoeff, unshieldedExposure)
%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
% ENGR 132
% Program Description
%  Calculates the gamma radiation exposure rate behind a metal shield.
%
% Assignment Information
%   Assignment:        #.#.#
%   Author:            Name, login@purdue.edu
%   Section/Team ID:   ###-##
%
% Function Call
%  shieldedExposure = gamma_exposure(thickness, attenuationCoeff, unshieldedExposure)
%
% Input Arguments
%  thickness - shield thickness (cm)
%  attenuationCoeff - linear attenuation coefficient (cm^-1)
%  unshieldedExposure - unshielded exposure rate (mR/hr)
%
% Output Arguments
%  shieldedExposure - shielded exposure rate (mR/hr)
%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%


%% ____________________
%% INITIALIZATION



%% ____________________
%% CALCULATIONS

shieldedExposure = unshieldedExposure .* exp(-attenuationCoeff .* thickness);


%% ____________________
%% FORMATTATED TEXT/FIGURE DISPLAYS

Notice that the function:

  • Uses the same argument names in the function definition line and calculations.

  • Assigns the calculated result to the output variable shieldedExposure.

  • Uses element-wise multiplication (.*) to support scalar and compatible array inputs.

  • Does not require initialization or formatted displays for this calculation.

The file must be saved as gamma_exposure.m in MATLAB’s current folder or another location on the MATLAB search path.

Calling the Function#

To execute a UDF, call it from the Command Window, a script, or another function.

For example:

exposure = gamma_exposure(0.5, 1.23, 10);

MATLAB assigns the values to the input arguments in the order they appear in the function definition line.

Input Argument

Value

thickness

0.5 cm

attenuationCoeff

1.23 cm\(^{-1}\)

unshieldedExposure

10 mR/hr

The function returns approximately 5.41 mR/hr, which is assigned to the variable exposure.

Input and Output Arguments

The variable names used when calling a function do not need to match the names in the function definition line. However, the order of the input arguments must match.

For example, gamma_exposure(10, 1.23, 0.5) produces an incorrect result because the shield thickness and unshielded exposure rate have been reversed.

A function can also be called using variables that have already been assigned values in the Command Window or a script.

For example:

%% INITIALIZATION

shieldThickness = 0.5;       % Shield thickness (cm)
leadCoeff = 1.23;            % Linear attenuation coefficient (cm^-1)
initialExposure = 10;        % Unshielded exposure rate (mR/hr)

%% CALCULATIONS

exposure = gamma_exposure(shieldThickness, leadCoeff, initialExposure);

This produces the same result as calling gamma_exposure(0.5, 1.23, 10) directly. Notice that the variable names in the function call (shieldThickness, leadCoeff, and initialExposure) are different from the input argument names in the function definition (thickness, attenuationCoeff, and unshieldedExposure).

MATLAB passes the values of these variables into the function in the order specified by the function definition line. The variable names do not need to match, but their order must be correct.

Similarly, the variable receiving the function’s output does not need to match the output argument name in the function definition line. For example, exposure receives the value of shieldedExposure when the function is called.
