6.1.2. PCA: Logic and Selection Structures#

Relational and logical operators allow MATLAB programs to compare values and evaluate multiple conditions. Selection structures use these conditions to determine which commands should execute.

In this activity, you will use relational and logical operators to evaluate arrays of measurements and construct a selection structure to classify the operating status of an industrial monitoring system.

Required Files#

Download the MATLAB Script Template and save it as username_6_1_2.m.

Using the MATLAB Template

Rename your file(s) with your Purdue username by replacing “template” in the filename. Then fill out any required information in the template, such as your name, email, and course details.

Instructions#

An industrial monitoring system collects temperature and pressure measurements to determine whether equipment is operating safely. Each temperature measurement corresponds to a pressure measurement collected at the same time.

The system uses the following acceptable operating limits:

  • Minimum temperature: 70 °C

  • Maximum temperature: 100 °C

  • Maximum pressure: 170 kPa

A temperature is considered unsafe if it falls below the minimum or exceeds the maximum. A pressure is considered unsafe if it exceeds the maximum.

Each temperature-pressure pair is considered unsafe if either measurement is outside its acceptable operating limits.

The system will be evaluated using the datasets provided in Table 6.8. Each dataset contains two arrays of equal length, where values at the same index represent measurements collected at the same time.

Part 1: Evaluate Operating Conditions#

Begin by initializing the temperature and pressure arrays using the values from Case 1 in Table 6.8. Also initialize the operating limits as variables.

Using relational and logical operators, write MATLAB code to:

  1. Determine the total number of temperature-pressure pairs and assign the result to numPairs. The number of pairs may vary between datasets.

  2. Create a logical array named unsafeTemp that identifies temperatures outside the acceptable range.

  3. Create a logical array named unsafePressure that identifies pressures exceeding the maximum acceptable pressure.

  4. Create a logical array named unsafeReadings that identifies temperature-pressure pairs where either measurement is unsafe.

  5. Calculate the total number of unsafe temperature-pressure pairs and assign the result to numUnsafe.

  6. Create a logical array named bothUnsafe that identifies temperature-pressure pairs where both measurements are unsafe.

Each logical array must have the same dimensions as the input measurements.

Part 2: Determine System Status#

Using the results from Part 1, write a selection structure that determines the overall system status.

Evaluate the following conditions in the order listed:

  1. Critical: More than half of the temperature-pressure pairs have at least one measurement outside the acceptable operating limits.

  2. High Risk: At least one temperature-pressure pair has both a temperature and a pressure outside their respective acceptable operating limits.

  3. Warning: At least one temperature-pressure pair has a temperature or pressure outside its acceptable operating limits.

  4. Normal: All measurements are within the acceptable operating limits.

Assign the appropriate classification to a string variable named systemStatus.

Classification Priority

The order of the conditions determines their priority. If multiple conditions are satisfied, the first applicable classification must be assigned.

Part 3: Display Results#

Using fprintf, display the results in the Command Window. Your output must include:

  1. The heading Industrial Monitoring System.

  2. The number of unsafe temperature-pressure pairs and the total number of pairs evaluated.

  3. The overall system status.

Format your output using the labels shown in the following example for Case 1:

Industrial Monitoring System
Unsafe Measurement Pairs: 0 of 6
System Status: Normal

Your output must update automatically based on the measurements being evaluated.

Part 4: Testing Your Code#

After completing your script, test it using all four datasets in Table 6.8.

For each test case:

  1. Replace the temperature and pressure arrays in the initialization section with the values from the corresponding dataset.

  2. Run your script.

  3. Compare the number of unsafe measurement pairs and the system status with the expected results in Table 6.9.

Your script must work for temperature and pressure arrays of varying lengths. Within each dataset, both arrays will contain the same number of elements.

Do not hardcode the number of measurement pairs, the number of unsafe pairs, or the system classification. These values must be determined by your code.

After testing all four datasets, restore the initialization arrays to the values from Case 1 before submitting your script.
