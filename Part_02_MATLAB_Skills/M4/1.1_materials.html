7.1.1. PCMs: Looping Structures#

Looping structures allow a program to repeat commands without writing those commands multiple times. In ENGR 131, you used loops in Python. This module builds on that experience by introducing MATLAB’s while and for syntax and showing how loops interact with selection structures and other loops.

Introduction to Looping Structures#

A repetition structure, or loop, repeats a block of commands. One complete execution of that block is called an iteration (or pass). Unlike a selection structure, which chooses a path and continues forward, a loop returns to its controlling decision to determine whether another iteration should occur.

MATLAB supports two common loop structures:

Table 7.1 Types of Loops in MATLAB#

Loop

Also Called

How Repetition Is Controlled

while

Indefinite loop

Continues while a logical condition remains true; the number of iterations may not be known in advance.

for

Definite loop

Iterates through a specified sequence of values; the number of iterations is determined by that sequence.

Selection vs. Repetition in Flowcharts#

Both selection and repetition structures use decision diamonds. In a selection structure, a decision determines which path is followed. In a repetition structure, a path returns to the decision, allowing the commands to execute again. When tracing a loop, pay attention to where control returns and when the exit condition is reached.

While Loops#

A while loop evaluates a logical condition before each iteration. If the condition is true, MATLAB executes the commands inside the loop. If it is false, MATLAB skips the loop or exits it and continues with the next command.

While Loop Syntax#

while logical_condition
    % commands to repeat
end

A typical while loop has three important parts:

  1. Initialization: Assign a starting value to the variable used in the condition before entering the loop.

  2. Condition: Define when the loop should continue.

  3. Update: Change a relevant value during the loop so the condition can eventually become false.

Example: Tracking Iterations#

MATLAB Code

Produces

 
counter = 1;

while counter <= 4
    fprintf('Iteration %d\n', counter);
    counter = counter + 1;
end

Iteration 1
Iteration 2
Iteration 3
Iteration 4

The condition is checked at the beginning of each pass. After the fourth iteration, counter becomes 5, so counter <= 4 is false and the loop ends. If the condition were false before the first iteration, the loop body would never execute.

Example: Repeating until a Target is Reached#

A while loop can also stop based on a calculated value rather than a fixed iteration count.

MATLAB Code

Produces

 
value = 3;
iterations = 0;

while value < 20
    value = value * 2;
    iterations = iterations + 1;
end

fprintf('Final value: %.0f\n', value);
fprintf('Iterations: %d\n', iterations);

Final value: 24
Iterations: 3

Here, the number of iterations depends on how many times the value must double to reach or exceed the target. The following table tracks how value changes during each iteration of the loop.

Table 7.2 While Loop Tracking Table#

At the beginning of each iteration, MATLAB checks whether value < 20. Since the condition is true for values of 3, 6, and 12, the loop continues. After the third iteration, value becomes 24. The condition is then false, so the loop terminates.

The final value is 24, and the loop executes 3 iterations.

MATLAB vs. Python

Python uses a colon and indentation to define a while loop body. MATLAB does not use a colon after the condition and requires an end statement to close the loop. Indentation is still recommended for readability, but not required to run.

Infinite Loops#

If a while condition never becomes false, the loop can continue indefinitely. Initialize the variables used in the condition, update them appropriately inside the loop, and test whether the loop terminates for different starting values.

For Loops#

A for loop repeats commands for each value in a specified sequence. In MATLAB, the loop variable receives one value from the sequence during each iteration.

For Loop Syntax#

for loopVariable = controlVector
    % Commands to repeat
end

A control vector supplies the values used by the loop variable. A common way to define these values is with the colon operator.

MATLAB Code

Produces

 
for k = 1:4
    fprintf('k = %d\n', k);
end

k = 1
k = 2
k = 3
k = 4

The colon notation start:step:stop allows a different increment:

MATLAB Code

Produces

 
for k = 2:3:11
    fprintf('%d\n', k);
end

2
5
8
1

If the step is omitted, MATLAB uses a step of 1.

Example: Using a Control Vector#

The values in the control vector do not have to be consecutive integers.

MATLAB Code

Produces

 
for measurement = [4, -1, 0]
    result = 2 * measurement + 5;
    fprintf('Measurement: %d, Result: %d\n', measurement, result);
end

Measurement: 4, Result: 13
Measurement: -1, Result: 3
Measurement: 0, Result: 5

Running Totals and Iteration Tracking#

A running total is a variable that keeps track of a result as a loop repeats. Initialize the variable before the loop, then update it during each iteration.

MATLAB Code

Produces

 
total = 0;

for k = 1:4
    total = total + k;
end

fprintf('Total: %d\n', total);

Total: 10

A tracking table helps verify that a loop updates variables in the expected order. Remember that MATLAB does not automatically save the intermediate value of every calculation; if you want to retain results from each iteration, you must store them.

MATLAB vs. Python

In Python, a definite loop often uses for k in range(1, 5):. In MATLAB, the equivalent sequence is commonly written for k = 1:4, followed by an end statement. Unlike Python’s range, MATLAB’s colon sequence includes the stop value when that value is reached by the step.

Nested Structures#

A nested structure is a programming structure placed inside another structure. In MATLAB, loops and selection structures can be combined to perform more complex tasks.

For example, a program might need to repeat a calculation several times, check a condition during each repetition, or perform one loop inside another.

Nested structures can include:

  • A for loop inside another for loop.

  • A while loop inside another while loop.

  • A for loop inside a while loop, or vice versa.

  • An if statement inside a for or while loop.

When one loop is placed inside another, it is called a nested loop. The loop containing the other loop is the outer loop, and the loop inside it is the inner loop.

Nested Loops#

In a nested loop, the inner loop executes during each iteration of the outer loop. The inner loop must finish before the outer loop continues to its next iteration.

MATLAB supports four combinations of nested for and while loops.

Table 7.4 Nested Loop Combinations#

Outer Loop

Inner Loop

Description

for

for

The inner for loop completes for each outer iteration.

for

while

The inner while loop repeats until its condition becomes false.

while

for

The inner for loop completes each time the outer while condition is true.

while

while

Both loops repeat based on their own logical conditions.

Regardless of the combination, the same general execution order applies:

  1. The outer loop begins an iteration.

  2. The inner loop executes until it finishes.

  3. MATLAB continues with any remaining commands in the outer loop.

  4. The outer loop begins its next iteration if another iteration is required.

Example: Nested for Loops#

The following example uses two for loops to display combinations of values.

MATLAB Code

Produces

 
for outer = 1:2
    for inner = 1:3
        fprintf('outer = %d, inner = %d\n', outer, inner);
    end
end

outer = 1, inner = 1
outer = 1, inner = 2
outer = 1, inner = 3
outer = 2, inner = 1
outer = 2, inner = 2
outer = 2, inner = 3

When outer = 1, the inner loop executes three times using the values 1, 2, and 3. After the inner loop finishes, the outer loop advances to outer = 2, and the inner loop executes three more times.

Example: while Loop Inside a for Loop#

A while loop can also be placed inside a for loop. This is useful when a calculation must repeat until a condition is met for each value in a control vector.

MATLAB Code

Produces

 
for target = [5, 10]
    value = 1;

    while value < target
        value = value * 2;
    end

    fprintf('Target: %d, Final: %d\n', target, value);
end

Target: 5, Final: 8
Target: 10, Final: 16

The outer for loop provides two target values: 5 and 10. For each target, value is initialized to 1. The inner while loop doubles value until it is no longer less than the current target.

Notice that value is initialized inside the outer loop but before the inner loop. This ensures that the calculation starts at 1 for each target.

Example: for Loop Inside a while Loop#

A for loop can execute inside a while loop. In this case, the inner for loop completes all its iterations each time the outer while loop repeats.

MATLAB Code

Produces

 
round = 1;

while round <= 2
    for number = 1:3
        fprintf('Round %d: %d\n', round, number);
    end

    round = round + 1;
end

Round 1: 1
Round 1: 2
Round 1: 3
Round 2: 1
Round 2: 2
Round 2: 3

The outer while loop repeats while round <= 2. During each outer iteration, the inner for loop executes three times. After the inner loop finishes, round increases by 1. The inner for loop executes 6 times in total across the two outer iterations.

Example: Nested while Loops#

Two while loops can also be nested. Each loop has its own logical condition and control variable.

MATLAB Code

Produces

 
outer = 1;

while outer <= 2
    inner = 1;

    while inner <= 3
        fprintf('outer = %d, inner = %d\n', outer, inner);
        inner = inner + 1;
    end

    outer = outer + 1;
end

outer = 1, inner = 1
outer = 1, inner = 2
outer = 1, inner = 3
outer = 2, inner = 1
outer = 2, inner = 2
outer = 2, inner = 3

This example produces the same output as the nested for loop example, but repetition is controlled by logical conditions instead of control vectors.

Pay attention to the placement of the variable updates:

  • inner is initialized to 1 each time the outer loop begins an iteration.

  • inner increases during each iteration of the inner loop.

  • outer increases after the inner loop finishes.

If inner were initialized before the outer loop instead, it would not reset to 1 during the second outer iteration. If either control variable were not updated correctly, its corresponding while loop might never terminate.

Selection Structures Inside Loops#

Loops can also contain selection structures. This allows a program to make decisions during each iteration.

Unlike a nested loop, an if statement does not repeat commands by itself. Instead, it determines whether specific commands should execute during the current iteration.

Example: if Statement Inside a for Loop#

The following example checks whether each number in a control vector is positive, negative, or zero.

MATLAB Code

Produces

 
for number = [4, -2, 0]
    if number > 0
        fprintf('%d is positive\n', number);
    elseif number < 0
        fprintf('%d is negative\n', number);
    else
        fprintf('%d is zero\n', number);
    end
end

4 is positive
-2 is negative
0 is zero

During each iteration, the for loop assigns a new value to number. MATLAB then evaluates the selection structure and executes the appropriate branch.

The selection structure is evaluated three times, once for each value in the control vector.

Example: if Statement Inside a while Loop#

Selection structures can also be placed inside while loops.

MATLAB Code

Produces

 
value = 1;

while value < 20
    value = value * 2;

    if value > 10
        fprintf('Value exceeds 10: %d\n', value);
    end
end

Value exceeds 10: 16
Value exceeds 10: 32

The while loop repeatedly doubles value until it reaches or exceeds 20. During each iteration, the if statement checks whether the updated value is greater than 10. The fprintf statement executes only when the condition is true.

Notice that the final value is 32, even though the loop condition is value < 20. This occurs because the condition is checked before each iteration, not immediately after value is updated.

Tracing and Testing Nested Structures#

Nested structures can be more difficult to follow because multiple conditions and variables may control the execution of commands.

When tracing nested structures:

  1. Identify the outer and inner structures.

  2. Determine the initial values of all control variables.

  3. Follow the commands in the order MATLAB executes them.

  4. Track how variables change during each iteration.

  5. Identify when each loop finishes and when the outer loop continues.

For nested while loops, verify that each loop has a condition that can eventually become false.

For loops containing selection structures, test values that cause each possible branch to execute.

When debugging nested structures, a tracking table can help identify incorrect variable updates, unexpected iteration counts, or loops that do not terminate.
