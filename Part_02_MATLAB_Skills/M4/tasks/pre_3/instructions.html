7.1.4. PCA: Nested Structures#

Nested structures combine one loop or decision structure inside another so a program can repeat a task in a controlled way. In this activity, you will interpret a flowchart that uses an outer loop and an inner decision loop to update variables until a stopping condition is reached.

Required Files#

Download the MATLAB Script Template and save it as username_7_1_4.m.

Instructions#

Study the flowchart below, then write a MATLAB script that follows its logic. Use the flowchart to guide the order of operations and loop control, translating it into MATLAB code exactly as shown. Follow the specified order, even if other approaches could also work. Confirm that your results match the expected output below.

        flowchart TD
  accTitle: Nested Loop Flowchart
  accDescr {
      The flowchart begins by accepting x and z as inputs.
      A control vector runs from -2 through 7 in increments of 3.
      For each value in the control vector, a inner loop
      checks whether z is greater than 6. If true, x decreases
      by 4, y becomes x squared, and z becomes half of y.
      The condition is checked again. When false, z increases
      by 2 and the outer loop continues. After the outer loop
      finishes, the final values of x and z are displayed.
    }

    Start([Start]) 
    Input[/Get user input for x and z/]
    ControlVec["Control vector starts at -2, ends at 7, and increments by 3"]
    Print[/Display x and z/]
    Stop([Stop])

    Start ==> Input ==> ControlVec
      
    subgraph OUTER
        direction TB
        For{"Are there more values in the control vector?"}
        ForY[Yes]
        ForN[No]


       ControlVec ==> For
       For ==> ForY ==> While
       For ==> ForN
       Calc4["Increase z by 2"]  

      subgraph INNER
            direction TB
            While{"Is z > 6?"}
            WhileY[Yes]
            WhileN[No]
            Calc1["Decrease x by 4"]
            Calc2["Set y = x^2"]
            Calc3["Set z = 0.5 * y"]

            While ==> WhileY ==> Calc1 ==> Calc2 ==> Calc3 ==> While
            While ==> WhileN 
      end
         
      WhileN ==> Calc4     
    end
    Calc4 ==> For
    ForN ==> Print ==> Stop
    
    %% Node styles
    classDef terminal fill:#000000,stroke:#000000,stroke-width:2px,color:#ffffff
    classDef inputOutput fill:#f3f4f6,stroke:#000000,stroke-width:2px,color:#000000
    classDef process fill:#ffffff,stroke:#000000,stroke-width:2px,color:#000000
    classDef decision fill:#ebd99f,stroke:#000000,stroke-width:2px,color:#000000
    classDef while_yes_no fill:#ffffff,stroke:none,color:#000000
    classDef for_yes_no fill:#f3f4f6,stroke:none,color:#000000

    %% Assign styles to nodes
    class Start,Stop terminal
    class Input,Print inputOutput
    class Calc1,Calc2,Calc3,Calc4,ControlVec process
    class ForY,ForN for_yes_no
    class WhileY,WhileN while_yes_no
    class For,While decision

    style OUTER fill:#f3f4f6,stroke:#000000,stroke-width:3px,color:#000000
    style INNER fill:#ffffff,stroke:#000000,stroke-width:3px,color:#000000
