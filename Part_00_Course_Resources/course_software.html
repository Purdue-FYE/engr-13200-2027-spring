Course Software#

ENGR 132 uses several software tools for programming, data analysis, visualization, and technical communication. Install or confirm access to the software below before it is needed for course assignments.

MATLAB#

MATLAB is the primary programming and data analysis environment used in ENGR 132. Purdue’s campus license provides access to:

  • MATLAB desktop

  • MATLAB Online

  • MATLAB Drive

  • MathWorks tutorials and training resources

Accessing MATLAB#

Use the Purdue MATLAB portal to access MATLAB through Purdue’s campus license.

You will need to create or sign in to a MathWorks account using your Purdue email address.

You may use either the desktop version of MATLAB or MATLAB Online unless an assignment provides different instructions.

MATLAB Help Documentation#

The MATLAB documentation provides descriptions, syntax, and examples for MATLAB functions and features.

If you are unsure how a function works, search the documentation using the function name. You can also access help directly from the MATLAB Command Window. For example:

help max

This displays information about the max function directly in MATLAB.

Microsoft 365#

Purdue students have access to Microsoft 365, including Excel, Word, and PowerPoint. These applications may be used throughout ENGR 132 for working with data, preparing documents, and communicating engineering work.

Installing Microsoft 365#

  1. Visit the Purdue Office 365 portal.

  2. Sign in using your Purdue account.

  3. Select the option to install Microsoft 365 applications.

  4. Follow the installer instructions for your computer.
